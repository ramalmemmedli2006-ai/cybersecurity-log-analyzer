# Cybersecurity Log Analyzer

A Python-based cybersecurity tool for analyzing system and authentication logs to detect suspicious activity such as failed login attempts, brute-force attacks, and unusual IP behavior.

---

## Project Overview

Cybersecurity Log Analyzer is a simple but practical security project that reads log files and identifies suspicious events.

This project is useful for:
- Security monitoring
- Detecting brute-force attacks
- Identifying suspicious IP addresses
- Learning log analysis in cybersecurity
- Building practical SOC-style projects for GitHub

---

## Features

- Parse authentication and system logs
- Detect repeated failed login attempts
- Identify possible brute-force activity
- Count events by IP address
- Generate a simple security report
- Export findings to a text file

---

## Technologies Used

- Python
- Regex
- File Handling
- Basic Security Analytics
